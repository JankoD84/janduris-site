# Personal Claims Review

Read:

- `.ai/repo/content-and-claims.md`
- `.ai/governance/personal-claims-and-truthfulness.md`
- `.ai/governance/public-content-and-pii.md`
- `.ai/process/review-workflow.md`

Check that each personal claim is supported by current approved site content, explicit owner-provided facts, or an authoritative source supplied for the task.

Reject unsupported strengthening of expertise, years, responsibilities, achievements, certifications, clients, customers, or language/proficiency levels.

Private AI context is not approved public content.
