# Project Claims and Cross-Repo Authority

## Scope

This site references external or ecosystem projects such as Dulvarn, Dulvarn Tools, Wildcode systems, and internal agent/AI workflows.

The portfolio may present these projects as part of the owner's public work. It does not own all domain truth about their implementation, architecture, maturity, production status, users, revenue, infrastructure, or roadmap.

## Required Authority

Before materially changing project/product claims, use one of:

- the canonical repository or documentation for that project
- explicit owner confirmation for the task
- current approved site content, only when preserving existing site wording without strengthening it

Do not hardcode cross-repository architecture into this site's standards. Ecosystem coherence belongs in a separate cross-repo layer.

## Dulvarn Claim Safety

Do not automatically treat portfolio wording as proof that a Dulvarn feature:

- is production-ready
- is live or generally released
- is publicly available
- has customers or usage
- has proven commercial adoption
- implements every marketed capability

Distinguish marketing positioning, implemented capability, and production/live state.

## Wildcode Claim Safety

Wildcode references can indicate public presentation of docs or systems, but do not prove current infrastructure topology, provider configuration, operational state, or private internal details.

## Stale Infrastructure Drift

Owner-declared current infrastructure truth for this wave:

- Scaleway is the current operational cloud provider.
- Hetzner is no longer the current provider.

Current site/README references to Hetzner or Hetzner VPS should be classified as stale or historical relative to that owner-declared current provider choice. Do not replace runtime content automatically in Standards work. Do not infer Scaleway resource IDs, products, IPs, regions, account identifiers, or configuration.
