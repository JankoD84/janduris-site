# Accessibility and Public UX

## Scope

This is a public professional portfolio. Accessibility and responsive usability affect both user experience and professional presentation.

## Considerations

For UI work, consider:

- semantic HTML
- keyboard navigation
- visible focus states
- form labels
- error/status feedback
- alt text for images if images are added
- color contrast
- reduced-motion behavior where animation exists
- responsive behavior across practical viewport sizes
- mobile navigation usability
- readable content hierarchy
- contact page usability
- CV page usability
- external-link usability

## Current Notes

Current source includes visible focus rings in many interactive elements, form labels, `role="status"` contact feedback, responsive layout classes, mobile navigation, and reduced-motion handling for the hero animation.

Do not claim WCAG compliance unless a formal accessibility audit or agreed validation has been performed.

## Validation

For UI changes, validate at relevant viewport sizes when practical. For animation changes, preserve reduced-motion behavior unless the task explicitly redesigns motion with an accessible alternative.
