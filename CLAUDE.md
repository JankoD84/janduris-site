Thin adapter for Claude-based agents working in `janduris-site`.

Use the repository-native instructions instead of duplicating governance here:

1. Start with `AGENTS.md`.
2. Read `.ai/repo/repository-context.md` and `.ai/repo/architecture.md`.
3. Classify the task with `.ai/repo/content-and-claims.md`.
4. Load only relevant `.ai/governance/*` files and `.agents/skills/*/SKILL.md` files.
5. Follow `.ai/process/implementation-workflow.md` or `.ai/process/review-workflow.md`.

Do not add biography, personal contact values, provider routing, model routing, secrets, or deployment credentials to this adapter.
